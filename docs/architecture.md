# Architecture and decisions

Design authority: [v1.1 copy](splitlink-design-v1.1.md), sourced without modification from `/Users/lukie/Documents/Codex/2026-10-22/ni-ka/outputs/splitlink-development-spec.md`. SHA-256 `65aa1d7adfdcdee7d97d862fc256f8b157e08c7757ef07020782b73d491f5987`. Design version is distinct from protocol version 1.0.0.

The contract has an immutable token, private records returned as complete structs, immutable ordered recipients/shares, no administrator, no custody, no upgrade path and no withdrawal. OpenZeppelin SafeERC20 and ReentrancyGuard protect all three writes. All calls use value zero. Failed transfers unwind the entire transaction; consumed gas does not unwind.

Hardhat 2 is the primary local contract runner because the bundled Node runtime was available and the repository had no existing toolchain. Standard local EVM tests deliberately do not claim Arc runtime equivalence. solc-js is pinned to 0.8.30, optimizer 200, Cancun output; the compile script generates actual Hardhat artifacts and the frontend ABI from one compilation without downloading a second compiler. Arc Osaka supports earlier Cancun bytecode; canonical integration remains a separate gate.

React + viem uses public chain-specific HTTP clients independently of injected-wallet connection. Wallet writes use the reviewed calldata through EIP-1193. Every operation simulates, estimates, checks funds, checks quote freshness and rechecks context before prompting. Approval is an independent step; absent payment gas hints remain unknown. No unlimited approval and no automatic reset/next-step signing. Current configured local mock uses resetRequired=false; no canonical reset policy is assumed.

A deployment allowlist validates chain, actual deployed runtime bytecode hash, immutable token and token decimals. Arc releases are intentionally absent. A local deployment manifest is fetched only if the bundle explicitly enables the fixture AND the browser and RPC are loopback AND chain is 31337. Routes cannot supply arbitrary deployments. The local token is a separate ERC20 asset and does not reproduce Arc shared native balance; local funding uses separate native gas while Arc formulas remain integer/shared. Never set local chain metadata to Arc.

The journal stores decimal bigint strings and frozen intent before prompting and stores returned hashes immediately. Reconciliation uses the original chain, exact sender/target/calldata/value/nonce, successful receipts and operation-specific verification at or after receipt block. Request status always comes from fresh reads, never the journal. A replacement candidate requires independently verified sender/nonce/call; other calls require a final receipt before superseding. No nonce/timeout heuristic establishes success or failure.

History uses exact indexed creator logs, inclusive newest-first ranges from deployment block, adaptive range shrinking, bounded retry/backoff and bounded reads. Successful creation logs and scan cursor are retained only in memory; retry resumes the inaccessible gap and new suffix, then rereads every discovered request. No authoritative local history cache is used. Context generations discard late results. Polling fetches only the new suffix/gap and request states. The active foreground page polls transaction/request state at five seconds and history at fifteen seconds.

Settlement evidence requires canonical Paid state/payer, the successful original-chain receipt, matching payRequest calldata, exactly one RequestPaid and ordered RecipientPaid allocations. Failed attempts and another session's payment remain distinct. Actual fees use receipt gasUsed × effectiveGasPrice. The app never infers an operation delta from observed wallet balances.

No backend, database, fee, relayer, indexer or private keys are added.
