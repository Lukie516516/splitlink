# Acceptance not established by local validation

This is a locally validated release candidate for independent review. It is not a statement that every v1.1 release/competition acceptance is complete.

1. No canonical Arc testnet or mainnet write, signing, deployment, approval/reset/self-transfer, shared native/ERC20 funding/gas, issuer blocklist/recipient rollback or measured preapproval hint was executed. Local ERC20 and test ETH are separate. Canonical self-transfer incompatibility would block release and require an explicit design revision; it must not be silently skipped.
2. No real public host was deployed. The actual intended HTTPS origin, remote deep-link/hard-refresh/assets, browser CORS, provider range/retention limits and failover are pending. Local Vite production preview and mocked RPC failure injection are supplemental evidence only.
3. No external wallet's live replacement/mempool behavior or full cross-browser/mobile-wallet matrix was tested. Production matching checks are unit/controller tested; standard RPC cannot universally discover sender+nonce replacements after browser close. No hash, storage loss and cross-device recovery remain explicitly limited.
4. The GitHub Actions workflow is prepared and its commands executed locally on macOS. It was not pushed or run on an actual Ubuntu hosted runner. Exact Linux native runtime/browser installation is therefore unobserved in this task. No hosted green badge or remote pipeline success is claimed for this candidate.
5. All five operation types were tested through the production controller at 25 saved-hash hydration checkpoints and with account/chain/context drift checks. Mounted browser tests cover the main flow, reset, cancellation, storage/unknown states and a delayed wallet-change path. Not every interruption point × operation × route × wallet timing permutation was separately tested in a real browser.
6. Fault injection covers unavailable/malformed evidence, missing identity, exact intent changes, row/log gaps, forged cache and storage denial. Mocks cannot reproduce all real canonical issuer controls, network consensus conditions, wallet overrides or provider pruning scenarios.
7. Current audit is a dated vulnerability-database observation, not a security audit or proof of absence of vulnerabilities. The build emits a non-failing >500 kB minified-chunk warning (~520 kB/~163 kB gzip). No performance SLA or independent contract audit is claimed.
8. Studio source provenance is real but partial. All continuation fixes/tests are external after export. Acceptability of external/imported work, full current event terms, entrant eligibility, cutoff/timezone, evidence/payment requirements and final submission are unresolved. No additional Studio activity, quota workaround or upgrade was attempted.

These are the remaining G1–G5/release limits. Local implementation and deterministic CI results must not be labeled canonical integration, public release, competition compliance or submission completion.
