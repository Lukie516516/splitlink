Canonical integration entry points: `pnpm check:arc` performs public reads. `pnpm test:arc` defaults to an explicit SKIPPED/BLOCKED result and never loads a signer on that path. `scripts/arc-integration.mjs` also contains a prepared **testnet-only** runner requiring both reviewed deployment/controlled-wallet configuration and the explicit `--execute-authorized-testnet-writes` flag. That branch was syntax-checked, **not executed or runtime-validated** in this task. Do not invoke it until the user authorizes those exact external writes.

It does not claim five-person/second-wallet/issuer-restriction/hosted coverage; those cases are explicitly unexecuted. It uses standard RPC and must itself be reviewed and validated on Arc before reliance.

Required process variables are printed by the default command. Supply a private signer key only through a secure process environment; never put it in a VITE variable, source file, command argument or report.
