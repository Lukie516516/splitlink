# SplitLink walkthrough plan

Use English captions or narration. Record real evidence; this script is not a claim that the steps have occurred.

1. **0:00–0:20 — Problem.** “A customer wants to pay a small team once. The team wants each member paid directly.” Show the public app and identify its actual network.
2. **0:20–0:45 — Build provenance.** Show the actual Arc Studio project URL, original work, contract tests and reviewed export revision. If this evidence does not exist, stop the competition recording; local mock footage cannot substitute.
3. **0:45–1:15 — Create.** Enter a public project title, a controlled small USDC amount and two recipient addresses. Show exact percentages, ordered allocations, zero platform fee and immutable terms. Record the actual creation transaction.
4. **1:15–1:45 — Independent customer.** Open the real payment link in a fresh browser context. Read terms without connecting. Connect the controlled payer, review exact USDC approval and network fee, and approve. Explain that approval is separate from payment.
5. **1:45–2:20 — Settle.** Refresh allowances and fees, review the payment and sign using the authorized wallet. Show the canonical Paid status and actual payer, recipient allocations and successful mainnet settlement hash on the explorer. Use only authorized funds and recipients.
6. **2:20–2:40 — Receipt and recovery.** Open the public receipt wallet-disconnected and hard-refresh it. Show My requests and the cancellation path for a separate unpaid request if available.
7. **2:40–3:00 — Tests and limits.** Show the exact reviewed commit and CI results. State browser recovery limits and any remaining real-network limitations honestly. End with public repository, app and Studio links.

Do not show seed phrases, private keys, account tokens, private billing details or device notifications. A final video URL and mainnet explorer link are recorded only after the actual recording and settlement.
